# EgyptianPlague

Here you can download the MALT bacterial database used in Gaul et al. (under review).

**Download**

The compressed database file can be downloaded directly using wget:

wget https://raw.githubusercontent.com/emilysgaul/EgyptianPlague/main/MALT_accessions_allBac_ref-rep_fullg-scaff_prescrVir_Sep2022_041_step3_cleaned.txt.gz

Alternatively, using curl:

curl -L -O https://raw.githubusercontent.com/emilysgaul/EgyptianPlague/main/MALT_accessions_allBac_ref-rep_fullg-scaff_prescrVir_Sep2022_041_step3_cleaned.txt.gz

**Decompression**

The downloaded file is compressed in gzip format. To decompress it, run:

gunzip MALT_accessions_allBac_ref-rep_fullg-scaff_prescrVir_Sep2022_041_step3_cleaned.txt.gz
